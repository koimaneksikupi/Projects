# Zero to Mastery — Machine Learning Projects

End-to-end machine learning and data science projects completed as part of the **Complete Machine Learning & Data Science Bootcamp: Zero to Mastery**.

> **Note on attribution:** These projects were built alongside the Zero to Mastery course curriculum to practice core ML workflows. 

## Core Workflow Practiced
Across these projects, I focused on following a structured machine learning workflow rather than jumping straight into modeling:
- **Exploratory Data Analysis (EDA):** Inspecting distributions, missing values, class imbalance, and correlations.
- **Preprocessing & Pipelines:** Handling missing data, encoding categorical features, scaling, and preventing data leakage.
- **Modeling & Baselines:** Starting with simple baseline models before moving to tree ensembles or neural networks.
- **Evaluation & Tuning:** Choosing appropriate metrics (accuracy, precision/recall, F1, MAE/RMSE, ROC-AUC) and tuning hyperparameters.
